Theme variations: warmer, calmer, no light windows

Five directions for the theme, 2026-11-25, design only. Each keeps the visual system (C4 keys, teak shelf boards, the filter bar with labels above its keys, the rating meter) and changes three things: warmer colours; no bright amber-to-coral gradient, so the primary key and the meter use one flat, muted accent; and no light windows: a chosen key is pressed down, its face takes a faint tint of the accent and its label the accent colour. The covers are bright on purpose, to judge the accent next to a lot of cover art. The current theme is first, for comparison.

Now (for comparison)

The current evening theme: amber-to-coral gradient on the primary key and the meter, and light windows on chosen keys.
