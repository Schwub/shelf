Copy a friend's tags

Superseded 2026-11-27: the built screen lists only the album's tags, none ticked, each going to any of my groups or tags (docs/features/tags.md). Adding an album from a friend's shelf opens the friend's whole tag tree. Each of their groups has a destination: the matching group of mine (same built-in key or name), any other group of mine, a new group like theirs, or none; the choice is remembered per friend, so the next album from them already goes the same way. Tags on the album are ticked; any other tag can be ticked too, to copy it into my tags without putting it on this album. Ticking a sub-tag brings its parent tag and group along. Marks say what is on this album, what I have already and what is new. Copy creates the new tags, then the album entry opens with the album's tags set. When there is nothing new and every group has a destination, the screen is skipped (a link on the entry still opens it). Replaces the import sheet of TASK-19.
