Import tags (M2)

After adding an album from a friend's shelf: the album remembers whose shelf it came from (“Added from Anna's shelf”, kept even if Anna's account is deleted); built-in tags are set automatically; tags you don't have are offered for copying. Copies are ordinary tags you can edit, and they stay even if you then cancel adding the album. A copied new group takes the friend's type (one or several). Built with M2. Flow: Add from a friend.
