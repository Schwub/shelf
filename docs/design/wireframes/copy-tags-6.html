A friend's tags, line by line: Add, Copy or Map (v6)

v6 (2026-11-27), after testing v5's chips: more control, one decision per screen. The album entry gets one row that opens Anna's tags: her tags on the album, one per line with the full path. Each line has Add (I have that path: my tag is set) or Copy (I don't: her path is created in my tags as it is, reusing the parts I have), and Map…. Map is three steps on their own screens: the starting point in her path, the place in my tags (browsed like folders; a tag of mine can also be used instead of hers), and a check that lists what is created and can bring everything else below the starting point along. Mappings are remembered per friend, so her next albums offer Add. Nothing is added by default; added lines say where the tag went and can be undone.
