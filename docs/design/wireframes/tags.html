Tags

The full tag editor, from ⋮ → Tags or “Edit tags” on an album. Changes save immediately; deletes ask first and take effect at once. Built-in groups (Collection, Listening) can be renamed and hidden, not deleted; only they can be hidden. Sub-groups go one level deep (like Format under Own). Flow: Tag editor.
