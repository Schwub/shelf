Select several albums (TASK-40)

Select several albums on My shelf (⋮ → Select albums, or press and hold one) and change them together: tags, hidden from friends, removed. While selecting, the app bar shows the count, ✕ to finish and Select all (the albums in the current filter); the filter bar still works, and albums already selected stay selected. The bottom row turns into Tags, Hide (Show when all selected are hidden) and Remove. Tags opens a sheet of all groups: a tag on all selected albums is ticked, on some shows –, with how many. Tapping a tag puts it on all of them; tapping a ticked one takes it off all; Apply saves. The usual rules hold: one tag per album in a one-per-album group (it replaces the other), and a sub-tag sets its parent tag. Hide and Remove act at once with Undo; Remove ends selecting. Back or ✕ ends selecting without changes. Later, not now: rating for many, export, selecting on a friend's shelf to add several.
