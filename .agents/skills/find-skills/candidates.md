# Skills: criteria and vetted candidates

Last checked: 2026-11-22. Updated through blueprint feedback and harvest.

## Sources worth checking first
- **Framework maintainers.** Flutter and Dart: `flutter/agent-plugins`
  (25 skills, includes all 15 of `dart-lang/skills`).
- **Anthropic:** `anthropics/skills`.
- **Directory:** `npx skills find` searches skills.sh. It has no review
  process: popularity is not vetting.

## Vetted

| Skill | Source | Licence | Use when | Notes |
|---|---|---|---|---|
| `frontend-design` | `anthropics/skills` | Apache 2.0 | The project has a user interface | Design direction, typography, a quality floor (contrast, focus, motion). Mostly stack-agnostic. |
| `flutter-apply-architecture-best-practices` | `flutter/agent-plugins` | BSD-3 | Flutter products | Layered UI / data / optional domain, MVVM, repositories. Suggests `freezed` or `built_value`: adding them is still a dependency decision for the user. |
| `flutter-add-widget-test` | `flutter/agent-plugins` | BSD-3 | Any Flutter app | `WidgetTester`, finders, interaction tests. |
| `dart-add-unit-test` | `flutter/agent-plugins` | BSD-3 | Any Dart or Flutter project | `package:test` structure and conventions. |
| `flutter-build-responsive-layout` | `flutter/agent-plugins` | BSD-3 | Apps for phone and tablet or desktop | `LayoutBuilder`, `MediaQuery`, breakpoints. |
| `flutter-add-integration-test`, `flutter-fix-layout-issues`, `dart-fix-runtime-errors` | `flutter/agent-plugins` | BSD-3 | Only with the Dart and Flutter MCP server set up | Built around MCP tools (`launch_app`, `get_runtime_errors`, `hot_reload`); without the server they lose most of their value. |
| `flutter-setup-localization`, `flutter-setup-declarative-routing` | `flutter/agent-plugins` | BSD-3 | When that decision is made | Install at the moment the project adds localisation or deep-link routing, not upfront. |

Notes on `flutter/agent-plugins`: generated by the Flutter team with a model
(see each skill's `metadata`), active (commits weekly), instructions and Dart
examples only, no executable scripts.
